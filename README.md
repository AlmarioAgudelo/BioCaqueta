# BioCaquetá

Sistema de Monitoreo de Biodiversidad y Avistamientos del Piedemonte Amazónico.

## Tecnologías
- Node.js
- Express
- Express Router
- Mongoose
- MongoDB Atlas
- Express-Handlebars

## Instalación

1. Clonar el repositorio.
2. Ejecutar `npm install`.
3. Crear el archivo `.env` utilizando `.env.example`.
4. Configurar la conexión a MongoDB Atlas.
5. Ejecutar `npm start`.
6. Abrir `http://localhost:3000`.

## Funcionalidades

- Registrar avistamientos.
- Consultar registros.
- Filtrar por categoría.
- Actualizar zona y estado de conservación.
- Eliminar avistamientos.
- Consultar la API REST mediante Postman.
